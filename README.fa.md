BenX مدیریت را از سرورهای VPN جدا می‌کند: رابط و API روی Worker، اطلاعات خصوصی روی D1 و هسته‌های VPN روی VPS خودتان اجرا می‌شوند. ترافیک VPN کاربران از Worker عبور نمی‌کند و همچنان به VPS نیاز دارید.

**نسخه ۰٫۹ پیش‌نمایش عمومی کد است.** تست خودکار جای بررسی اتصال کلاینت، نصب واقعی Cloudflare، تونل و پرداخت واقعی را نمی‌گیرد و تضمین نبودن همه باگ‌ها نیست.

## تفاوت‌ها و دلیل آن‌ها

| طراحی | فایده |
| --- | --- |
| میزبانی پنل روی Worker و D1 | برای خود پنل وب‌سرور جداگانه نگهداری نمی‌کنید. |
| ارتباط خروجی HTTPS عامل | برای مدیریت بومی، پورت عمومی عامل یا رله SSH مشترک لازم نیست. |
| حالت بومی و اتصال اختیاری به 3X-UI | می‌توانید آداپتور بومی یا پنل موجودِ پشتیبانی‌شده را انتخاب کنید؛ امکانات دو حالت متفاوت‌اند. |
| پروفایل و نسخه تنظیمات | تغییرات بررسی‌شده متمرکز می‌مانند و قابلیت پشتیبانی‌نشده صریح رد می‌شود. |
| فرمان و نتیجه رمز‌شده و ماندگار | هر عامل هویت جدا دارد؛ عملیات حساس شروع‌شده کورکورانه تکرار نمی‌شود. |
| مالک، مدیر و نماینده | دسترسی سرورها، مشتریان، سهمیه و فروشگاه اختیاری را محدود می‌کنید. |
| رابط فارسی و انگلیسی | راست‌به‌چپ، واکنش‌گرا، تم روشن و تاریک و راهنمای دو زبان. |

پروژه ادعای برابری کامل با پنل‌های دیگر، افزایش سرعت VPN به‌دلیل میزبانی مدیریت روی Cloudflare یا حذف نیاز به مدیریت لینوکس ندارد.

## نصب سریع

۱. **Deploy to Cloudflare** را بزنید و با حساب خودتان وارد شوید. مخزن در حساب Git شما کپی و دیتابیس خصوصی `DB` آماده می‌شود.

۲. نوع پروژه **Worker**، مسیر ریشه، Node.js **24**، دستور ساخت `npm run build` و انتشار `npm run deploy` را انتخاب کنید.

۳. پس از پایان انتشار، لینک خصوصی و یک‌بارمصرف انتهای گزارش Cloudflare را باز کنید.

۴. **Create my login & sign in** را بزنید و نام کاربری و رمز تولیدشده را ذخیره کنید. ثبت‌نام عمومی وجود ندارد.

۵. از **Getting started → Connect your VPS → Direct agent connection** فایل خصوصی را بگیرید، بررسی کنید و روی VPS خودتان با root اجرا کنید.

۶. وضعیت عامل و هسته را بررسی و قبل از استفاده تجاری، اتصال واقعی، انقضا، سهمیه پشتیبانی‌شده و لغو دسترسی را تست کنید.

کلیدها و جدول‌ها خودکار ساخته می‌شوند و ارتقای عادی آن‌ها را حفظ می‌کند. دامنه `workers.dev` کافی است و دامنه اختصاصی اجباری نیست. گزارش انتشار، لینک راه‌اندازی و فایل بازیابی را خصوصی نگه دارید.

```sh
git clone https://github.com/BenTheBuilder-BenX/BenX-UI.git
cd BenX-UI
npm ci
npx wrangler login
npm run deploy
```

## امکانات و محدودیت‌ها

مدیریت بومی Xray، OpenVPN، ocserv/OpenConnect، OpenSSH، WireGuard، DNS resolver و MasterDnsVPN؛ ورودی، مشتری، سرویس، اشتراک، QR، پروفایل، تونل WireGuard/SSH/FRP، اتصال سازگار به 3X-UI و فروشگاه اختیاری تلگرام در پروژه وجود دارند. پشتیبانی حسابداری و ساخت کاربر به هسته و حالت اتصال بستگی دارد.

نصب مستقل sing-box و Hysteria 2، اعمال عمومی IP/HWID در حالت بومی، تبدیل دلخواه دیتابیس پنل‌ها، جایگزینی خودکار شناسه منطقی عامل خروجی، وضعیت آنلاین بومی و کپی کامل OS پیاده‌سازی نشده‌اند. سهمیه و اولین استفاده فقط در آداپتور دارای اندازه‌گیری معتبرند. MasterDnsVPN مستقل بدون حسابداری است؛ حالت مشترک VLESS فقط داده داخلی را می‌شمارد، نه سربار DNS.

عامل پیش‌فرض هر سه ثانیه polling می‌کند؛ ظرفیت و هزینه Cloudflare باید متناسب با تعداد سرورها بررسی شود. پاسخ فرمان ممکن است بعد از ۲۵ ثانیه نامشخص شود؛ قبل از تکرار عملیات حساس، وضعیت واقعی را بررسی کنید.

نصب‌کننده برای Debian 12/13 یا Ubuntu 24.04/26.04 با x86-64/ARM64 و systemd است. HTTPS سالم، فایروال، forwarding/NAT و بررسی کلاینت واقعی مسئولیت مدیر میزبان است.

## توسعه و امنیت

Node.js 24 و Python 3.11+ پیشنهاد می‌شود. با `npm ci` وابستگی‌ها را نصب، با `npm run setup:local` محیط خصوصی محلی را آماده و سپس `npm run worker:dev` و `npm run dev` را در دو ترمینال اجرا کنید.

```sh
npm run release:check
npm run release:package
```

کد عمومی بدون فایل‌های عملیاتی، کلیدها، شناسه حساب/دیتابیس شخصی، گزارش‌ها و فونت با حق بازتوزیع نامشخص بسته‌بندی می‌شود. [راهنمای فارسی](docs/guide.fa.md)، [SECURITY.md](SECURITY.md) و [چک‌لیست پذیرش](docs/release-acceptance.md) را بخوانید. کلید رمزگذاری نصب موجود را عوض نکنید.
