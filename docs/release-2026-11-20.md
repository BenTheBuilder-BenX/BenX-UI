# BenX-UI v0.9.0-preview.2 — 2026-11-20

## English

This update publishes the locally saved client-list and dashboard improvements. It remains a public source preview. Existing installation and recovery instructions still apply: [English setup](easy-install.md), [Cloudflare operations](cloudflare.md), and [release acceptance](release-acceptance.md).

- **Faster client lists:** traffic lookup is indexed once per inbound, stream settings are parsed once per inbound, and online/attachment filters use sets instead of repeatedly scanning every client.
- **Server switching:** the Clients page remounts for the selected server, resetting its local selection, filters and editor state.
- **Online status:** background saved-configuration refreshes preserve the last online list; a live refresh still replaces it with current results.
- **Metrics errors:** invalid or missing live CPU metrics return an explicit unavailable status while saved inbounds remain accessible. Saved-only and unbound views do not falsely report a live-metrics error.
- **Denied API reads:** an HTML access-denied response such as HTTP 403 is no longer retried. Safe reads still receive the existing bounded recovery for transient failures or malformed successful responses. Mutations are not replayed.
- Regression tests cover invalid live metrics with preserved saved inbounds and HTML access denial without a duplicate request.

### Validation

`npm run release:check` passed locally: TypeScript/ESLint, 426 application tests in 45 files, 116 agent tests, production build, published sample exclusion, fresh local workerd/D1 installation and account checks, 12 authenticated API read routes with anonymous isolation, outbound pairing/polling, SSH runtime checks and relay build.

Initial production JavaScript measured 78,453 bytes gzip, below the 140,000-byte budget. The official npm advisory scan reported zero known vulnerabilities, including development dependencies, on 2026-11-20. The release package excludes private runtime files, workspace account/database IDs, operational logs and supplied font binaries; it includes source checksums.

These results do not establish a live Cloudflare account installation, real VPS/client connectivity, tunnel quality, payment delivery or production capacity. This publication does not perform a live Cloudflare deployment. Keep full D1 backups and the original recovery keys before updating an existing installation.

## فارسی

این نسخه بهبودهای ذخیره‌شده محلی فهرست مشتریان و داشبورد را منتشر می‌کند و همچنان پیش‌نمایش عمومی کد است. [راهنمای کامل فارسی](guide.fa.md) و دستورهای نصب، ارتقا و بازیابی قبلی معتبرند.

- **فهرست سریع‌تر مشتریان:** اطلاعات ترافیک برای هر ورودی یک‌بار نمایه‌سازی، تنظیمات اتصال یک‌بار پردازش و فیلتر آنلاین/اتصال با مجموعه‌ها بررسی می‌شود؛ جست‌وجوی تکراری در تمام مشتریان کمتر شده است.
- **تغییر سرور:** صفحه مشتریان برای سرور انتخاب‌شده دوباره ساخته می‌شود تا انتخاب‌ها، فیلترها و وضعیت ویرایش قبلی به سرور دیگر منتقل نشوند.
- **وضعیت آنلاین:** تازه‌سازی پس‌زمینه تنظیمات ذخیره‌شده، آخرین فهرست آنلاین را حفظ می‌کند؛ تازه‌سازی زنده همچنان نتیجه جدید را جایگزین می‌کند.
- **خطای آمار:** آمار زنده فاقد CPU معتبر، وضعیت ناموجود و پیام روشن برمی‌گرداند؛ ورودی‌های ذخیره‌شده در دسترس می‌مانند. نمای صرفاً ذخیره‌شده یا سرور متصل‌نشده خطای زنده کاذب نمی‌گیرد.
- **رد دسترسی API:** پاسخ HTML با خطای دسترسی مانند 403 دوباره ارسال نمی‌شود. بازیابی محدود برای خواندن امن در خطاهای موقت حفظ شده و عملیات تغییر داده تکرار نمی‌شود.

بررسی محلی کامل موفق بود: **۴۲۶ تست برنامه و ۱۱۶ تست عامل، در مجموع ۵۴۲ تست**، بررسی نوع و کد، ساخت نهایی، نصب تازه با workerd و D1 محلی، بررسی ورود و نشست، ۱۲ مسیر خواندن API، جفت‌سازی عامل، ارتباط SSH آزمایشی و ساخت رله. اسکن رسمی npm در تاریخ ۲۰۲۶-۱۱-۲۰ آسیب‌پذیری شناخته‌شده‌ای گزارش نکرد.

این تست‌ها جای نصب با حساب واقعی Cloudflare، اتصال واقعی VPN، کیفیت تونل، پرداخت و سنجش ظرفیت عملیاتی را نمی‌گیرند. این انتشار کد، استقرار زنده Cloudflare انجام نمی‌دهد. پیش از ارتقای نصب موجود، بکاپ کامل D1 و کلیدهای اصلی بازیابی را نگه دارید.
